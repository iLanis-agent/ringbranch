# Ringbranch 1.0 TEST
Native Java/Canvas Android 8+ Wagiri diagonal loop-membership puzzle.

Put one diagonal in every cell. Tap a cell to flip its diagonal. Gold numbers on grid points count touching diagonal ends. A cell marked L must have its diagonal on at least one closed loop. A cell marked C must not have its diagonal on any closed loop. Unmarked cells have no loop-membership restriction. Loops are allowed, with no single-loop requirement. Twelve unique 4x4 clue-and-mark boards have twelve distinct solutions. L and C are English labels for the Wagiri loop and cut clues.

Saved diagonal palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens the browser.

Independent Java removes each marked diagonal and searches for an alternate endpoint path to decide loop membership, checking all 65536 diagonal assignments per board against production Tarjan bridge detection and degree counts. Exactly one solution each; bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only; not final or Play published.

Current 803-entry registry, 120 partial recovered README records and exact Edgewillow cumulative stage found no Wagiri match. Shares Branchvale Slant diagonal flips and vertex degree clues, but mandatory loop membership and non-membership replace the universal no-loop forest constraint. Every board has both L and C marks; each solution contains a loop, so no Branchvale solution is legal here. Loopglade single orthogonal border loop differs from multiple unrestricted diagonal loops with marked-edge membership. Known Wagiri genre, not a global invention. Partial recovered corpus, not ALL-local. Rules https://puzzles.covering.space/genres/wagiri and http://meanderlawn.blogspot.com/2021/12/lazy.html .
